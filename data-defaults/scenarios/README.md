# Example plans

Illustrative plans for the **fictional** starter household (`../profile.starter.json`:
Alex, born 1975-03; Jordan, born 1977-09). They are not seeded into the data folder —
the app has one plan, created by `loadPlan()` on first read. They exist as worked
examples of the event vocabulary, and as parse/round-trip fixtures for
`tests/scenario-helpers.test.ts`.

Retirement is mid-2030 throughout (Alex turns 55, so the 72(t) bridge matters) and
Social Security is claimed at each person's own FRA of 67 — 2042-03 and 2044-09.
